# FastAPI OCR Engine

A fast, free, and simple OCR (Optical Character Recognition) API built with FastAPI and EasyOCR.

## Features
- Extracts text from uploaded images.
- Fast execution using FastAPI.
- Free and open-source models (EasyOCR).
