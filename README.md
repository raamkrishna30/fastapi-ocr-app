# FastAPI OCR Engine

A fast, free, and simple OCR (Optical Character Recognition) API built with FastAPI and EasyOCR.

## Features
- Extracts text from uploaded images.
- Fast execution using FastAPI.
- Free and open-source models (EasyOCR).

## How to Run

1. Clone the repository:
   ```bash
   git clone <your-repo-link>
   cd my-ocr-api
2. To create an virtual environment
   ```bash
   python -m venv venv
   venv\Scripts\activate
3. To install requirements
   ```bash
   pip install -r requirements.txt
4. To run
   ```bash
   uvicorn main:app --reload
